# 🚦 YOLOv8 Traffic Signal Detection

This project implements a deep learning pipeline using YOLOv8 to detect traffic signals (such as stop, yield, speed limit, etc.) in images and videos. The model was trained on a custom road signs dataset and tested on real-world footage to demonstrate practical applications in autonomous driving and smart city infrastructure.

## 📌 Project Highlights

- **Model Used:** YOLOv8 (Ultralytics)
- **Task:** Object Detection – identifying and localizing multiple types of traffic signs
- **Dataset:** Custom road sign dataset annotated for training
- **Tools:** Python, Roboflow, OpenCV, Ultralytics YOLOv8, Google Colab
